# Security Log Analyzer

A Python-based tool for analyzing authentication logs and detecting suspicious login activity.

## Features

- Parse and validate authentication log records.
- Analyze successful and failed login attempts.
- Calculate login success and failure rates.
- Identify suspicious IP addresses and user accounts.
- Detect consecutive failed login attempts.
- Generate a security analysis report.

## Technologies

- Python 3
- IP Address Validation
- Log Parsing
- Security Event Analysis

1. Clone the repository.

```bash

```
